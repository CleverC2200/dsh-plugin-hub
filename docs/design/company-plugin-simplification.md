# 公司插件页精简

面向业务同事，在宿主设置对话框中查看公司提供的少量插件、安装所需功能、管理已安装项。沿用宿主字体、主题色和设置页视觉，不引入独立品牌装饰。

| 原有内容 | 当前处理 | 原因 |
| --- | --- | --- |
| 四个一级菜单 | 公司插件、已安装 | 常用任务只需浏览和管理 |
| 自定义安装、设置 | 技术维护下展开 | 保留支持入口，不占据业务主导航；这不是权限隔离 |
| 11 个分类、Star/Fork 排序 | 移除 | 三款公司插件无需公共市场筛选机制 |
| 搜索和结果计数 | 超过 8 项才显示搜索，移除重复计数 | 小目录直接看全 |
| 推广条幅、源码、关注、语言切换 | 移除 | 语言跟随宿主，业务任务无需跳转仓库 |
| 卡片版本、分类、标签、统计 | 名称、用途、安装状态和动作 | 用途优先；桌面分发项明确提示通过桌面更新 |
| 已安装行内路径和卸载 | 管理详情中保留 | 避免误操作，运行状态仍用文字表示 |
| 桌面更新完整发行列表 | 一行摘要；可用更新按需展开 | 同版本不再展示，失败和待重启状态不隐藏 |
| 渠道、检查间隔设置 | 不在业务页提供 | 延续桌面已有设置，不修改默认渠道、检查频率或授权 |

布局采用自然文档流，插件列表不再单独滚动；条目以细分隔线分组。标题 20px、插件名称 15px、正文 13px，正文行高 1.7；按钮至少 34px 高，键盘焦点可见。窄窗口条目纵向排列。

## 验证和接入边界

已在独立本地预览中验证真实构建产物，使用明确标注的演示安装状态；没有执行安装、卸载或重启。预览不能证明实际安装服务成功。

当前工作目录为 company-catalog 分支；已安装桌面来自 company-plugin-updates 发行分支，其桌面更新后端不在当前目录。新增 DesktopUpdates 兼容现有 /dsh-plugin-hub/desktop-updates 协议；没有该端点的 Web 宿主不显示更新区。接入发行版时应合入这些客户端变更并重新构建发行包，保留发行分支后端保护与更新协议，不以当前分支后端覆盖发行版。

未修改宿主提供的通用设置、模型、插件、Agent 预设等左侧菜单；该仓库只负责公司插件内容区域。
